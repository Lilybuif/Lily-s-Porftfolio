Project Overview

Webformafy is a full-stack form builder and integration platform that enables users to create, manage, and integrate forms with popular CRM and marketing tools. The application features responsive, mobile-first UIs with dark mode, reusable components, and consistent styling across forms, dashboards, and subscription management workflows.

Technical Implementation

Designed and built a complete web application using ASP.NET Core Razor Pages, C#, and SQL Server. The frontend implements responsive, mobile-first interfaces with HTML5, CSS3, Bootstrap 5, and JavaScript, including dark mode support, reusable UI components, and consistent styling across all workflows.

Key Features

  • Responsive, mobile-first form builder UI
  • Dark mode and consistent design system
  • Reusable UI components across forms, dashboards, and subscription management
  • Subscription tiers and payment processing
  • Integrations with HubSpot, Salesforce, Mailchimp, and Google Sheets
  • Full CRUD operations for form creation and management

Technology Stack

  • Payment processing integration
